# Commando Workshop

見下ろし型・縦スクロールの小さなシューティングゲームです。AIコーディングエージェント（Claude Code、Codex、OpenCode）を使ってゲームの土台づくりを学ぶ、ハンズオンワークショップの出発点として使います。

![](docs/screenshot.png)

## 実行

```sh
pnpm install
pnpm dev
```

操作: **WASD** 移動 · **マウス** 照準 · **クリック** 射撃 · **Space / 右クリック** 手榴弾 · **R** リスタート。

捕虜を救出し、最上部までたどり着いてください。トーチカと戦車には銃弾が効きません。手榴弾を使うか、近くの赤いドラム缶を利用してください。

## このブランチ: 演習2、データ + エディタ

レベルと敵は TOML ファイルで `data/` にあり、ゲームの横のページにエディタがあります。

- **マップを編集する:** *Terrain*（地形）または *Units*（ユニット）を選び、パレットから選んで、マップ上をクリックまたはドラッグします。Shift+ドラッグで矩形を塗りつぶし、
  右クリックでカーソル下の内容を拾い、⌘Z / ⇧⌘Z で元に戻す／やり直します。行番号をクリックすると、*Play from row*（その行から開始）の開始位置を選べます。
  マップ上の青い枠はゲームが表示している範囲、黄色い点はプレイヤーです。
- **敵を編集する:** *Enemies* タブに、敵の種類ごとのフォームがあります。能力値、移動の仕組み1つ、攻撃の仕組み1つです。
  *Clone as new type* で、コードに触れずに新しい種類を作れます（例えばもっと速いスナイパー）。
- **保存**（⌘S）すると `data/levels/<name>.toml` と `data/enemies.toml` に書き込まれ、ゲームが読み込み直します。ほかの手段（テキストエディタやコーディングエージェント）で
  ファイルが変更された場合も同じように再読み込みされます。ファイルが不正な場合は、ゲームは最後に有効だったバージョンで動き続け、パネルに問題点が表示されます。
  コマンドラインからは `pnpm check:data` でファイルを検証できます。
- **レベル:** ドロップダウンでレベルを切り替えます（URL の `?level=name`）。*New…* で空のレベルを作ります。
- **開発用のみ:** エディタとファイル API は `pnpm dev` の一部です。`pnpm build` で作ったゲームはレベルを読み込めません。

ファイル形式は、各データファイルの冒頭と `AGENTS.md` に記載されています。

## 演習

資料は `workshop/` にあります（まず `workshop/README.md` から。日本語版は `workshop/ja/`）。

1. **ハードコード**（`main`）: レベルは `src/level.ts` 内のテキストグリッドで、挙動はコードで書かれています。機能やエフェクトを追加します。
2. **データ + エディタ**（このブランチ、完成版）: レベルと敵の定義を TOML ファイルに移し、レベルエディタとホットリロードを用意します。
3. **エディタの中のエージェント**（完成版は `exercise-3` ブランチ）: エディタがヘッドレスのコーディングエージェントを呼び出し、依頼に応じてレベルを編集させます。
