# ワークショップ資料

今日は、Commando 風の小さなシューティングゲームを題材に、その周りの**ツール**を作ります。作るのは AIコーディングエージェントを使ってです。
ゲーム自体はあえて素朴にしてあります。大事なのは、まず自分たちが、次にエージェントが、ゲームを内側から形づくれるようにする土台のほうです。

```
 ハードコードのゲーム  →  データファイル + エディタ  →  データを編集してくれるエージェント
     （演習1）                 （演習2）                      （演習3）
```

## 一日の進め方

- **AIコーディングツールが必要です。** Claude Code、Codex、OpenCode のうち、普段使っているものを使ってください。
- **演習は3つ、順番に。** それぞれにゴールと「完了条件」のチェックリストがあり、時間があれば発展課題もあります。採点はしません。
- **自分で作るか、完成版を使うか。** いつでも自由に選べます。
  - *自分で作る:* エージェントと一緒に演習を実装します。
  - *完成版を使う:* 完成版に切り替えて遊んでみて、それから壊してみてください。これは残念賞ではなく、れっきとした選択肢です。
  - 切り替えはコマンド1つで、自分の作業は安全に残ります（下記参照）。
- **まずゴール、それから発展課題。** 演習2または演習3で残り約10分になってもゴールに近づいていなければ、完成版に切り替えてください。次の演習で必要になります。
- **大事なのは皆さんの判断です。** 私たちのテストでは、エージェント単独で各ゴールに10〜20分で到達しました。残りの時間は、判断し、確認し、作られたものを理解することに使ってください。各演習に「プロンプトの前に決めること」のリストがあります。

| 演習 | 時間 | |
|---|---|---|
| [00 セットアップ](00-setup.md) | 15分 | クローン、インストール、実行、エージェントの確認 |
| [01 自分のものにする](01-make-it-yours.md) | 40分 | 機能とエフェクト、並行するワークツリーでのオーディオ |
| [02 データとエディタ](02-data-and-editor.md) | 40分 | レベルと敵をファイルに、ホットリロード、マップエディタ |
| [03 エディタの中のエージェント](03-agent-in-the-editor.md) | 40分 | エディタがコーディングエージェントにマップの編集を依頼する |
| [チートシート](agent-cheatsheet.md) | | ワークツリー、ヘッドレスモード、ポート、マージコンフリクト、レート制限 |
| [制約カード](constraints.md) | | 演習1で引く、任意の「ありあわせで作る」ルール |

## 完成版

演習2と演習3の完成版は、このリポジトリのブランチ `exercise-2` と `exercise-3` にあります。
エージェントには、指示がない限りそれらを覗かないよう伝えてあります。自分の作業に触れずに使うには:

```sh
git worktree add ../commando-exercise-2 exercise-2     # or exercise-3
cd ../commando-exercise-2 && pnpm install && pnpm dev --port 5174
```

各ブランチは前のブランチの上に積み重なっており、それぞれの `README.md` と `AGENTS.md` に内容が説明されています。

## 最後にレベルを見せる

一日の最後のパートでは、各自がベストのレベルを、自分のノートPCかプロジェクターで見せます。コピーや送信は不要です。
